Create a fully professional and feature-rich website called GfxStore — a next-generation Minecraft + VPS Marketplace Platform with complete user and admin systems, built using Next.js + TailwindCSS + Framer Motion (or equivalent modern stack).


---

🌐 OVERVIEW

GfxStore combines all Minecraft content (Plugins, Mods, Panels, Tools, Scripts) and VPS/Server plans in one place.
The system must include:

Full user system (login, profile, dashboard)

Advanced admin control panel

Built-in payment (bKash, Nagad)

Auto translation

Advanced search, analytics, and management system

Modern, fast, and gaming-inspired UI similar to Modrinth + Nebula Panel + BuiltByBit



---

Quick stats: Total downloads, purchases, uploaded items, messages.

Order status (Pending / Paid / Delivered).

Analytics for own uploads (views, downloads, earnings).

Built-in user wallet to track earnings from paid content.

Withdraw balance to bKash or Nagad (admin approval required).


Notifications Center:

Payment confirmations, new comments, update requests, etc.

Real-time updates with WebSocket or Firebase.


Support System:

Built-in ticket system for support queries.

Chat-style UI for communication with admins.


Security Settings:

2FA (Two-Factor Authentication).

Login history and device tracking.


Badges & Ranks:

Automatic badges for verified developers, top sellers, contributors, etc.

Premium subscription to unlock faster downloads or special themes.
